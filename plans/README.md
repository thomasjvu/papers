The local execution pass has closed the release-identity, security-boundary,
template, asset, browser, quality/performance privacy, maintainer,
multi-collection/MDX, generated OpenAPI, collection search, route-preload, and
SEO/agent-discovery slices. `papers` is still not 10/10 for general users

project-relevant static content/API surface, but not equivalent to the full
Fumadocs ecosystem or every interactive playground/plugin integration.

## Findings considered and rejected

- **Immediate Fumadocs migration**: rejected for now. The repository now has a
  meaningful static-host, visual, collection, and generated-reference surface;
  migration would add framework/runtime coupling before a concrete missing user
  journey justifies it.
- **SSR as the first fix**: deferred. The project explicitly targets static
  deployment and already emits route HTML; broken verification and route
  contracts are higher leverage. Revisit SSR/prerender only after the static
  contract is green.
- **Environment-local npm cache failure**: not a repository finding. The audit
  observed `npm cache verify` failing with `EPERM` under `/Users/area/.npm` and
  `npm outdated` failing on registry DNS; neither is evidence of a code defect.
- **Lint warnings as standalone release blockers**: tracked for cleanup inside
  the relevant plans, but not split into a separate plan. The lint command exits
  zero; correctness and release-gate failures have priority.
- **A new proprietary agent protocol**: rejected. Existing Markdown/JSON
  artifacts plus ordinary alternate links are sufficient and keep the static
  host contract portable.

- `npm ci`, `npm test`, `npm run lint`, `npm run format:check`,
  `npm run type-check`, `npm run build`, `npm run check:docs`,
  `npm run release:check`, and `npm run release:preview-check` pass from a
  clean checkout.
- Every published route has one documented canonical URL and one verified
  static-file/host behavior on Cloudflare Pages and Vercel (or one host is
  explicitly removed from the support promise).
- Source Markdown/MDX, navigation, generated JSON, LLM exports, SEO output,
  and route HTML are checked from one deterministic pipeline; missing or
  malformed content fails the build rather than becoming a placeholder page.
- Runtime dependencies with reachable high/critical advisories are patched or
